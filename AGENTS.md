## Julia Documentation

- Follow Julia's standard docstring conventions.
- Document public APIs and non-obvious internal functions.
- Keep docstrings concise and technically precise.
- Explain arguments, return values, and numerical conventions where necessary.
- Document normalization assumptions and statistical estimators.
- Use inline comments only to explain non-obvious reasoning.
- Avoid comments that merely describe what the code does.
- Do not generate boilerplate documentation.
- Preserve existing documentation style.
